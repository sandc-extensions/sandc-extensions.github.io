California Daily Overtime and Code TT: What Counts

Only the federal overtime premium counts for code TT. California's daily overtime counts only where it overlaps with hours over 40 in the week.

Code TT is the half-time premium the federal Fair Labor Standards Act requires for hours over 40 in a workweek. Overtime that California requires but federal law doesn't, like daily overtime in a week under 40 hours, is not qualified overtime (IRS FS-2026-13).

Why the first week is $0

California requires time-and-a-half after 8 hours in a day, so four 10-hour days earn 8 hours of daily overtime. But the week totals exactly 40 hours, so federal law requires no overtime, and the W-2 code TT amount is zero. The employee still gets the California overtime pay. It just isn't reported as qualified overtime.

Double time

When California requires double time, only the federal half-time portion counts, and only for hours over 40 in the week. The extra pay above time-and-a-half is not qualified overtime, as the IRS's own double-time example shows.

How to enter California weeks

Enter total hours worked in the workweek and the straight-time rate. Don't enter the daily overtime or double-time pay. The calculator only looks at hours over 40, which is exactly the federal rule.

Questions

Is California daily overtime qualified overtime?

Only to the extent the hours are also over 40 in the federal workweek. Daily overtime in a week of 40 hours or less is required by state law, not the FLSA, so it isn't reported in code TT.

Does double time count for code TT?

Only the federally required half-time premium counts. The extra amount paid above time-and-a-half is not qualified overtime.
